# Compile Test Structure README

## Compile Tests

These are regular compile-tests at the level of unit tests.

**pass/\*.rs:** examples that are expected to compile
**fail/\*.rs:** examples that are expected to not compile


## Documentation Example Tests

These are compile-tests used to prove the feasability of the examples publicly shared in documentation.

**pass/docs/\*.rs:** examples in existing documentation that compile
**fail/docs/\*.rs:** examples from previous version that have broken compatibility
**historical/docs/\*.rs:** examples that have been retired or retained for reference but with no compatability checks
